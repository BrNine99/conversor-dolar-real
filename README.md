# 💱 Conversor de Moedas

Aplicação web desenvolvida com **HTML, CSS e JavaScript** que permite converter valores entre Dólar Americano (USD) e Real Brasileiro (BRL).

O projeto foi criado com o objetivo de praticar lógica de programação, manipulação do DOM, eventos e funções em JavaScript.

## 🚀 Funcionalidades

- Conversão de Dólar (USD) para Real (BRL).
- Conversão de Real (BRL) para Dólar (USD).
- Atualização automática dos valores durante a digitação.
- Formatação dos valores com duas casas decimais.
- Interface simples e responsiva.

## 🛠️ Tecnologias utilizadas

- **HTML5:** estrutura da aplicação.
- **CSS3:** estilização e responsividade.
- **JavaScript:** lógica de conversão e interatividade.
- **Git:** controle de versões.
- **GitHub:** hospedagem do código-fonte.

## ⚙️ Como executar

1. Clone o repositório ou baixe os arquivos do projeto.
2. Abra a pasta no Visual Studio Code.
3. Abra o arquivo `index.html` no navegador.
4. Digite um valor em um dos campos para realizar a conversão.

## 🧠 Conceitos praticados

Durante o desenvolvimento deste projeto, foram utilizados:

- Declaração de variáveis com `let`.
- Funções e parâmetros.
- Estruturas condicionais (`if`).
- Manipulação do DOM com `querySelector()`.
- Eventos `keyup` e `blur` com `addEventListener()`.
- Conversão de strings para números com `parseFloat()`.
- Formatação numérica com `Intl.NumberFormat()`.
- Operações matemáticas.

## 💵 Cotação utilizada

Atualmente, a aplicação utiliza uma cotação fixa de:

**1 USD = R$ 5,10**

A cotação está definida diretamente no JavaScript e não é atualizada automaticamente.
